The cost-per-request formula

cost/req = (Ti ÷ 1,000,000) × inPrice + (To ÷ 1,000,000) × outPrice

Where Ti = input tokens per request, To = output tokens per request. Current Claude rates (USD per 1M tokens):

ModelInputOutputCache readBatch in / out

Per-day = cost/req × R × 60 × 24; per-month = per-day × 30, at sustained 24/7 load (the calculator's assumption). Real apps with diurnal traffic cost less.

Example 1 — support chatbot on Haiku 4.5

Short prompts, short answers: Ti = 1,500, To = 400, at 100 req/min.

  • cost/req = 1,500/1e6×$1 + 400/1e6×$5 = $0.0015 + $0.0020 = $0.0035
  • per day (100 RPM × 1,440 min = 144,000 req): $504
  • per month (×30): $15,120

This is the cheapest current Claude model and the right default for high-volume chat. A long fixed system prompt cached at $0.10/M (vs $1/M) would cut the input portion ~90%.

Example 2 — RAG app on Sonnet 4.6

Large retrieved context, moderate answer: Ti = 12,000, To = 800, at 30 req/min.

  • cost/req = 12,000/1e6×$3 + 800/1e6×$15 = $0.036 + $0.012 = $0.048
  • per day (30 RPM × 1,440 = 43,200 req): $2,073.60
  • per month (×30): $62,208

RAG cost is dominated by retrieved input tokens. Caching a stable corpus prefix at $0.30/M instead of $3/M is the highest-leverage optimization here — and those cache reads also stop counting toward ITPM.

Example 3 — coding agent on Opus 4.7

Large context, substantial generation: Ti = 15,000, To = 3,000, at 10 req/min.

  • cost/req = 15,000/1e6×$5 + 3,000/1e6×$25 = $0.075 + $0.075 = $0.15
  • per day (10 RPM × 1,440 = 14,400 req): $2,160
  • per month (×30): $64,800

Agents re-send a large, mostly-stable context every turn — the canonical caching workload. With the prefix cached at $0.50/M instead of $5/M, the input portion drops from $0.075 to ~$0.0075, taking cost/req to ≈ $0.0825 (≈45% off here, more when input dominates).

The two big levers

Caching: cache read = 0.1× base input → about 90% off the cached input portion, and cache reads do not count toward Anthropic's ITPM rate limit.   Batch API: 50% off both input and output for async work that tolerates a delay.

FAQ

How do I calculate the cost of a Claude API request?
(Ti/1e6)×inPrice + (To/1e6)×outPrice. Opus 4.7 = $5/$25, Sonnet 4.6 = $3/$15, Haiku 4.5 = $1/$5 per million.
How much does prompt caching save?
Cache read = 0.1× input (Opus $0.50 vs $5/M) → ~90% off the cached portion, and it does not count toward ITPM.
How much does the Batch API save?
50% off both input and output for async workloads — e.g. Opus 4.7 $2.50/$12.50 instead of $5/$25.
Which Claude model is cheapest for a chatbot?
Haiku 4.5 ($1 input / $5 output per million) — the cheapest current Claude model and the usual default for high-volume chat.
